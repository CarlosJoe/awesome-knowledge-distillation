### P1-01：MNIST 基础蒸馏实验

| 字段 | 内容 |
|------|------|
| **案例编号** | P1-01 |
| **案例名称** | MNIST 基础蒸馏实验 |
| **所属阶段** | 第一阶段（入门） |
| **难度等级** | ★☆☆ |
| **前置知识** | 了解知识蒸馏基本概念、PyTorch 基础 |
| **前置案例** | 无 |
| **数据集** | MNIST（手写数字，60K 训练 / 10K 测试） |
| **教师模型** | TeacherNet：FC(784→1200) → FC(1200→1200) → FC(1200→10)，带 Dropout(0.2) |
| **学生模型** | StudentNet：FC(784→800) → FC(800→10) |
| **核心蒸馏方法** | Response-based KD（Hinton 2015） |
| **损失函数** | L = α·T²·KL(p_t^T \|\| p_s^T) + (1-α)·CE(y, p_s^1) |
| **关键超参数** | T=4.0, α=0.7, optimizer=Adam(lr=1e-3), epochs=10 |
| **评估指标** | Top-1 准确率 (%) |
| **预期结果** | 教师 ~99.3%，学生(蒸馏) ~99.1%，学生(基线) ~98.5%，蒸馏提升 +0.6% |
| **参考代码** | stage1 文档第 5.1~5.2 节 |
| **扩展挑战** | ① 删除某类训练数据（如数字"3"），观察蒸馏模型的零样本识别能力；② 尝试更小的学生模型（如 400→10） |

### C. 常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 蒸馏后学生不如基线 | T 值过大或 α 值不当 | 降低 T 到 2~4，调整 α 到 0.7 |
| 训练损失不收敛 | 学习率过大 | 降低学习率，使用 CosineAnnealing |
| 特征蒸馏维度不匹配 | 教师-学生通道数/空间尺寸不同 | 添加 1×1 卷积对齐通道，使用插值对齐空间 |
| RKD/CRD 效果差 | Batch size 太小 | 增大 batch_size 到 64+ |
| DeepInversion 生成图像质量差 | BN 统计量损失权重不够 | 增大 bn_weight 到 5~10 |
| TinyBERT 效果差 | 缺少数据增强 | 添加 BERT MLM 数据增强 |
| GPU 内存不足 | 模型/批次太大 | 减小 batch_size，使用梯度累积 |
